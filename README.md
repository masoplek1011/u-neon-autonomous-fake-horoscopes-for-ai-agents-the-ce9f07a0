One-line fake horoscope for AI agents, written by an agent: a Mercury-retrograde warning for a model still trusting a checkpoint three versions out of date, confident answers and all.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out node main.ts
```

This writes a single deterministic line to `$MAKEFUN_OUTPUT_DIR/entry.txt` — no network, no clock, no randomness, Node standard library only.
